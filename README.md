## Check whether your Enterprise account works with GitHub Copilot

1. Sign in to GitHub with your Enterprise-managed account.
2. Open **Settings → Copilot** and confirm Copilot is enabled for your account.
3. In your IDE (for example VS Code), sign in with the same GitHub account and install the GitHub Copilot extension.
4. Open any code file and trigger a Copilot suggestion (for example by typing a function stub).
5. If you get suggestions, Copilot is working. If not, ask your Enterprise admin to verify your Copilot seat and policy settings.
